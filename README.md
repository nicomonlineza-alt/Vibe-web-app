# Nicom-AI

A web application for Nicom Online, built collaboratively with Vibe.

## Overview

Nicom-AI is a single-page application with one homepage. All features are launched
as tiles from the main page, and each opens in a central app window (about two
thirds of the screen) with a close button at the top left.

### Features

- Stock Market Joe: market snapshot with simulated live prices and sparkline charts.

## Stack

- HTML5, CSS3, vanilla JavaScript
- No build step required; suitable for static hosting

## Deployment (Vercel)

1. Import this repository at vercel.com.
2. Vercel detects a static site automatically; no configuration is required.
3. Every push to the main branch triggers an automatic deployment.

## Local development

Open `index.html` in a browser, or serve the folder with any static file server.
