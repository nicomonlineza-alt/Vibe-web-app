# Nicom-AI

### Social Sally

A sales and marketing advisor. Sally asks four questions (industry, area of
operation, website address, description of services), saves the company
profile locally, and produces a tailored plan: industry snapshot, competitor
research task, local opportunities, positioning guidance, marketing channels,
a ninety-day action plan and KPIs. Plans are generated from a built-in
industry knowledge base; live web research on named competitors requires a
backend service to be connected later.
