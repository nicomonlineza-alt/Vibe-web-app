
### AI connection (serverless)

Sally's strategic analysis is generated by a Mistral AI model through the
Vercel serverless function `api/ask.js`. To activate it:

1. Create a free API key at console.mistral.ai.
2. In the Vercel project settings, add the environment variable
   `MISTRAL_API_KEY` with that key.
3. Redeploy. Sally will then include an AI-written strategic analysis in every
   plan. Without the key, Sally gracefully falls back to her built-in plan.

The key lives only on the server; it is never sent to the browser.
